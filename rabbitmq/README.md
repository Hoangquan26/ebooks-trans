  1. **Giữ trọn vẹn 100% nội dung sách gốc:** Đầy đủ mọi chương, mục, tiểu mục, đoạn văn, hộp ghi chú (`NOTE`, `TIP`, `WARNING`), sidebar, chú thích chân trang, `Summary`, mọi đoạn mã (`Listing` bằng Python, Erlang, Java, C#, PHP, Bash), bảng biểu (`Bảng`) và hình minh họa (`Hình`).
